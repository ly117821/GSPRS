# GSPRS

The implementation code will be made publicly available upon publication of the article.

The repository will include:

- implementation of GSPRS;
- G3C: Graph-guided Coarse-to-Fine Classifier;
- ASCN: Adaptive Semantic Compensation Network;
- training and evaluation scripts;
- configuration files;
- instructions for reproducing the experiments on KITTI and BDD100K.

## Dataset

This work uses the public KITTI and BDD100K datasets. The original datasets should be downloaded from their official websites. We do not redistribute the original images or annotations.

## Code Availability

The code is currently under organization and will be released after the article is officially published.
